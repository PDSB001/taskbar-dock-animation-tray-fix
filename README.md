# Taskbar Dock Animation – Tray Fix

Magnifies Windows 11 taskbar app buttons and Widgets on hover. The system tray stays at its normal size, including the input method and volume icons.

Independent distribution based on Taskbar Dock Animation 1.9.2 by [Ph0en1x-dev](https://github.com/Ph0en1x-dev). Maintained by PDSB001 under the MIT license.

## Install

1. Download `taskbar-dock-animation-tray-fix.wh.cpp` from the release.
2. In Windhawk, disable any other taskbar hover animation mod. Open **Create a new mod**, replace the template with the downloaded source, and compile.
3. Enable **Taskbar Dock Animation – Tray Fix**. To animate Widgets, leave **Exclude system buttons** at 0.

Windhawk development tools are needed to compile locally. The tray fix was tested on Windows 11 Insider build 26340.9882 with Windhawk 2.0 alpha 8 (x64).
