# Taskbar Dock Animation – Enhance

Magnifies Windows 11 taskbar app buttons and Widgets on hover. The system tray stays at its normal size, including the input method and volume icons.

Independent distribution based on Taskbar Dock Animation 1.9.2 by [Ph0en1x-dev](https://github.com/Ph0en1x-dev). Includes four-edge and multi-monitor support from Taskbar Dock Animation Plus 2.0.1 by incconutwo. Maintained by PDSB001 under MIT.

Enhance adds per-app animation profiles. Set a specific app to Dock wave, single-icon zoom, or no animation, and optionally override its magnification. It also supports taskbars on all four screen edges and secondary displays, and offers a separate Widgets animation toggle.

## Install

1. Download `taskbar-dock-animation-tray-fix.wh.cpp` from the release.
2. In Windhawk, disable any other taskbar hover animation mod. Open **Create a new mod**, replace the template with the downloaded source, and compile.
3. Enable **Taskbar Dock Animation – Enhance**. To animate Widgets, leave **Exclude system buttons** at 0.

Windhawk development tools are needed to compile locally. The tray fix was tested on Windows 11 Insider build 26340.9882 with Windhawk 2.0 alpha 8 (x64).
